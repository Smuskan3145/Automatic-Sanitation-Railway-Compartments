## 📌 Overview
An IoT-based automated sanitation system built for railway compartments that uses sensors to detect toilet dirtiness and automatically triggers a spraying robot to sanitize — eliminating manual cleaning and ensuring consistent hygiene for millions of railway passengers.

## 🎯 Problem Statement
Indian Railways serves over 23 million passengers daily. Railway toilet hygiene is a major challenge — manual cleaning is slow, inconsistent, and unhygienic. Our system provides a fully automated solution using IoT sensors and a spraying robot for real-time detection and instant sanitization.

## ⚙️ How It Works
1. Sensors continuously monitor toilet cleanliness
2. When dirty condition is detected, signal sent to Arduino
3. Arduino processes the signal and triggers the robot
4. Spraying robot automatically sprays sanitizer
5. System confirms cleaning and resets for next cycle
